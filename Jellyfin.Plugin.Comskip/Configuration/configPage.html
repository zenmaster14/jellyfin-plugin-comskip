Comskip commercial detection

Detected commercials are published as Commercial media segments. Each user chooses what happens in Settings → Playback → Media segments (“Ask to skip” or “Skip”).

Processing

Remuxes into a clean temporary copy first, so corrupt OTA packets don't crash comskip. The original file is never modified.
Restart Jellyfin after changing.
Protects against analyzing a file a post-processor is still writing.

Segments

A little padding avoids skipping the first seconds of the show.
For Kodi / MPV. Requires write access to the media folder.

Remove commercials (permanent)

This permanently rewrites your .ts recordings and keeps no backup. Only Live TV recordings are cut. Turning this on also cuts every recording that has already been analyzed. Wrongly detected show content is lost for good. Cuts are made on keyframes without re-encoding, so up to about a second of a commercial can remain at each join. Files that are being watched are cut later.
If detection would remove more than this, the file is left alone and skip segments are used instead.
